# Python Task 3 - Contact Book

## Description

This project is a Command Line Interface (CLI) based Contact Book developed using Python. It allows users to manage contacts by adding, viewing, searching, and deleting contact details. The contacts are stored in a list of dictionaries during program execution.

## Features

- Add New Contact
- View All Contacts
- Search Contact by Name
- Delete Contact
- Menu-Driven CLI Interface

## Technologies Used

- Python 3
- Visual Studio Code

## Data Structure

- List
- Dictionary

## How to Run

1. Open Terminal.
2. Navigate to the project folder.
3. Run the following command:

```bash
python contact_book.py
```
